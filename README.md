# calculatorReceiption

카드 영수증 PDF를 자동으로 분석해 **지출비상세정산서(Excel)** 와 **영수증 합본(PDF)** 을 생성하는 Go 기반 자동화 도구입니다.

---

## 개발 배경

매달 반복되는 경비 정산 작업을 자동화하기 위해 만들었습니다.

기존 방식:
1. 개별 카드 영수증 PDF를 하나씩 열어 날짜/금액/가맹점 확인
2. Excel 정산서에 수동으로 행마다 입력
3. 영수증 PDF를 하나씩 합쳐서 제출용 파일 생성

자동화 후:
```
calculator input/05
```
한 줄로 Excel + 합본 PDF 동시 생성

---

## 개발 과정

### 1단계 — 데이터 구조 파악

먼저 기존 4월 정산 데이터(PDF 영수증, Excel 정산서)를 분석했습니다.

- **영수증 PDF 분석**: `ledongthuc/pdf` 라이브러리로 텍스트 추출 시도
  - 국내 카드 전표(매출전표): 글자가 세로로 한 자씩 추출됨 → 전체를 이어붙인 후 정규식으로 파싱
  - 해외 카드 전표(해외승인전표): 정상 추출됨

- **Excel 정산서 분석**: `excelize` 로 셀 위치 확인
  - 좌측 데이터 컬럼: `B=일자, C=계정no, D=계정, E=사용금액, F=목적, G=참석자, H=사용자`
  - 우측 계정 합계 테이블: `J=계정NO, N=합계` (계정 X → 행 8+X 고정)
  - 합계: `N77`, 총계: `E86`

### 2단계 — PDF 파싱 구현

국내 영수증에서 추출한 연속 문자열을 정규식으로 분해:

```
합계([\d,]+)원       → 결제 금액
가맹점명(.{1,20}?)업종 → 가맹점명
업종(.{1,10}?)대표자명 → 업종(한식/일식 등)
(\d{4}-\d{2}-\d{2})  → 거래 날짜
```

### 3단계 — 해외 결제 처리

해외 카드 전표는 USD 금액만 있고 원화 금액이 없는 문제 발생.
→ `input/{월}/overrides.json` 파일로 수동 보완하는 방식 도입:

```json
[
  {
    "file": "5_16.pdf",
    "amountKRW": 33203,
    "accountNo": 65,
    "account": "재료비",
    "purpose": "AI 도구",
    "note": "CLAUDE.AI 22USD × 환율1512.50 + 수수료66원"
  }
]
```

### 4단계 — Excel 생성

템플릿 Excel을 열어 데이터 행만 교체하는 방식:
- 기존 서식/병합 셀/우측 계정 테이블은 유지
- 좌측 데이터 행(9~76행)만 초기화 후 재입력
- 계정별 합계를 집계해 우측 N열 업데이트
- 제목(연월), 팀원명 자동 업데이트

### 5단계 — 템플릿 분리

매달 input 폴더에 템플릿을 복사하던 방식 → `metaData/` 폴더로 분리:

- `metaData/지출비상세정산서_DigitalTwinLab_전계범_샘플.xlsx` 한 번만 저장
- 출력 파일명은 `샘플` → `26.04` 자동 치환

### 6단계 — PDF 합본 생성

`pdfcpu` 라이브러리로 개별 영수증 PDF를 날짜순으로 병합:

```
4_01.pdf + 4_03.pdf + ... + 4_28.pdf → 4월 지출경비영수증_전계범.pdf
```

### 7단계 — 이미지 동반 파일 처리

원화환산 증빙을 스크린샷(`.jpg`)으로 저장한 경우 처리:
- `5_16_2.jpg` 처럼 `*_2` 이름의 이미지 파일 자동 감지
- A4 크기 PDF로 변환 후 해당 영수증 바로 뒤에 삽입

```
5_16.pdf → 5_16_2.jpg(→A4 PDF 변환) → 5_21.pdf → ...
```

## 폴더 구조

```
calculatorReceiption/
├── main.go                  # 메인 프로그램
├── config.json              # 사용자 설정 (이름, 카테고리 규칙)
├── go.mod / go.sum          # Go 모듈
├── calculator.exe           # 빌드된 실행 파일 (Windows)
│
├── metaData/
│   └── 지출비상세정산서_*_샘플.xlsx   # 정산서 템플릿 (공용)
│
├── input/
│   └── {월}/               # 예: 04, 05
│       ├── *.pdf            # 개별 영수증 PDF
│       ├── *_2.jpg          # 원화환산 증빙 이미지 (옵션)
│       └── overrides.json   # 해외결제 등 수동 보완 데이터
│
└── output/
    └── {월}/               # 입력과 동일한 월 구조
        ├── 지출비상세정산서_*_26.04.xlsx
        ├── 4월 지출경비영수증_전계범.pdf
        └── *_2.pdf          # 변환된 이미지 PDF
```

## 사용 방법

### 실행

```bash
calculator input/05
```

### 월별 준비 사항

| 파일 | 필수 여부 | 설명 |
|------|----------|------|
| `input/{월}/*.pdf` | 필수 | 카드 영수증 PDF (파일명: `{월}_{일}.pdf`) |
| `input/{월}/overrides.json` | 해외결제 시 | 원화 금액, 계정 정보 수동 지정 |
| `input/{월}/*_2.jpg` | 옵션 | 원화환산 증빙 이미지 |
| `metaData/*샘플*.xlsx` | 필수 | 정산서 양식 템플릿 |

### PDF 파일명 규칙

```
{월}_{일}.pdf       예: 5_07.pdf (5월 7일)
{월}_{일}_2.jpg     예: 5_16_2.jpg (5월 16일 증빙 이미지)
```
